# 🚀 GitHub Explorer

*GitHub Explorer* is an interactive dashboard built with *React.js* that allows users to explore trending GitHub repositories. It fetches real-time data from the *GitHub REST API* and provides features such as search, sorting, filtering, bookmarking, note-taking, and analytics visualization using *Chart.js. The interface is styled with **Tailwind CSS* for a modern and responsive UI.

---

## 🔹 Features

- 🔍 *Search* repositories by name  
- ⭐ *Sort* by Stars, Forks, or Last Updated  
- 🌐 *Filter by language* (JavaScript, Python, Java, TypeScript, C++, etc.)  
- 📦 *Repository Cards* displaying repository details: name, description, stars, forks, language  
- 🔖 *Bookmarking & Notes* saved in localStorage  
- 📊 *Analytics: Bar chart showing Top 5 repositories by stars using **Chart.js*  
- 🎨 *Responsive UI* styled with *Tailwind CSS*

---

## 🛠 Tools & Technologies

- *React.js* – Frontend framework  
- *GitHub REST API* – Fetch trending repositories  
- *Chart.js + react-chartjs-2* – Analytics visualization  
- *Tailwind CSS* – Styling framework  
- *LocalStorage* – Saving bookmarks and notes
